# Read these before deciding how to drive a run

rl-mcp is the harness this studio is a window onto, and it documents itself for
agents. **These files are the authority; this harness is not.** If something
here disagrees with them, they win, and the fix is to correct this file.

Do not re-derive what they already say, and do not write your own version of
their advice into a scratch file — that is the exact failure `AGENTS.md` opens
by describing.
