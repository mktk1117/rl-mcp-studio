Client module check

See also checks.html, which loads the app at a laptop size and walks every view for layout faults.

The client has no build step and no Node toolchain, so a syntax error in a client module is not caught before the browser tries to load it — and when that happens the app is simply a blank page. This imports every module the way the app does and says which ones failed. Open it after editing web/js: /static/dev/modules.html.
